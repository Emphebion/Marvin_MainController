; runeconfig.txt — 48 candidate rune definitions (6 per button)

; Shape templates used (applied to each of the 8 button positions):
;   Conduit — 5 consecutive LEDs in the middle of the flow arc (FA:3-7)
;   Shard   — 6 LEDs at the trailing end of the flow arc, approaching the button junction
;   Lance   — 5 LEDs at the leading edge of the counter arc, from the button junction
;   Span    — 8 LEDs crossing the button junction (4 from FA end + 4 from CA start)
;   Hook    — 6 LEDs: 3 from the CW bridge outer section + 3 from the flow arc start (L-shape outward)
;   Prong   — 7 LEDs: 4 from the CW bridge inner section + 3 from the adjacent middle ring arc (inward reach)
;
; For each button the adjacent segments are:
;   FA  = flow arc (outer ring, clockwise of button)
;   CA  = counter arc (outer ring, counter-clockwise of button)
;   BCW = bridge clockwise of button (outer end BCW:8 is physically adjacent to FA:0)
;   MID = middle ring arc connected to BCW inner end (BCW:0 adjacentt to MID:last)
;
; Button  ->  FA        /  CA        /  BCW      /  MID
;   east      segm48(11) / segm49(11) / segm40(9) / segm24(8)
;   northeast segm50(10) / segm51(11) / segm41(9) / segm25(8)
;   north     segm52(11) / segm53(11) / segm42(9) / segm27(8)
;   northwest segm54(11) / segm55(11) / segm43(9) / segm29(8)
;   west      segm56(10) / segm57(11) / segm44(9) / segm31(8)
;   southwest segm58(11) / segm59(11) / segm45(9) / segm33(8)
;   south     segm60(11) / segm61(11) / segm46(9) / segm35(8)
