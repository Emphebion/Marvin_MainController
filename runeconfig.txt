; runeconfig.txt — 48 candidate rune definitions (6 per button)
;
; All runes use COMPLETE segments so shapes are large (22–40 LEDs each),
; matching the reference designs in docs/design_assets/Runes/Rune Example 1-3.png.
;
; Six shape templates, each using 2–4 full segments:
;
;   Outer Pair      — FA + CA  (2 outer arcs crossing the button junction)          ~22 LEDs
;   Right Spoke     — BCW + FA + MID  (bridge + outer arc + middle arc, L-right)    ~28 LEDs
;   Left Spoke      — CA + BCCW + MID  (outer arc + bridge + middle arc, L-left)    ~28 LEDs
;   Outer Triple    — prev + FA + CA  (3 consecutive outer arcs)                    ~33 LEDs
;   Outer Horseshoe — BCW + FA + CA + BCCW  (both bridges + both outer arcs, U-out) ~40 LEDs
;   Inner Horseshoe — BCW + MID1 + MID2 + BCCW  (both bridges + middle arcs, U-in) ~34 LEDs
;
; Segment roles per button  (FA=flow arc, CA=counter arc, BCW=CW bridge, BCCW=CCW bridge):
;
;   Button    FA(LEDs) CA(LEDs) BCW  BCCW  MID_BCW MID_BCCW prev_FA  IH_mid1 IH_mid2
;   east      48(11)   49(11)   40   41    24      25       63       24      25
;   northeast 50(10)   51(11)   41   42    25      27       49       26      27
;   north     52(11)   53(11)   42   43    27      29       51       28      29
;   northwest 54(11)   55(11)   43   44    29      31       53       30      31
;   west      56(10)   57(11)   44   45    31      33       55       32      33
;   southwest 58(11)   59(11)   45   46    33      35       57       34      35
;   south     60(11)   61(11)   46   47    35      37       59       36      37
;   southeast 62(11)   63(11)   47   40    37      24       61       38      39
;
; BFS cross-segment connections used (all verified valid after bidirectional fix):
;   Outer Pair:      FA:last  -> CA:0           (FA flows to CA)
;   Right Spoke:     BCW:8    -> FA:0            (BCW flows to FA)
;                    BCW:0    <- MID:7           (BCW counter, bidirectional)
;   Left Spoke:      CA:last  -> BCCW:0          (CA flows to BCCW)
;                    BCCW:0   <- MID:7           (BCCW counter, bidirectional)
;   Outer Triple:    prev:last <- FA:0            (FA counter, bidirectional)
;   Outer Horseshoe: BCW:8 -> FA:0, FA:last -> CA:0, CA:last -> BCCW:0
;   Inner Horseshoe: BCW:0 <- MID1:7, MID1:7 -> MID2:0, MID2:7 -> BCCW:0
